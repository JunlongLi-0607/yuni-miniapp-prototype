# 芋泥小程序交互原型 v0.1

直接用 Chrome 或 Edge 打开同目录的 `index.html`，无需安装依赖。桌面左侧为页面目录，中央为可点击小程序，右侧为当前页面说明。窄屏自动显示为全屏小程序。浏览器本地保存演示数据，左侧可以重置。

`overview.html` 将全部 17 页并排展示，适合先评审页面框架，再进入单屏走流程。总览用独立示例状态，不改动单屏原型数据。

## 设计依据

- 依据提供的视频截图与流程、功能清单三张图和手绘草图。
- 沿用草图的「首页 / AI / 我的」底部导航。
- 原有「录音 → AI 摘要与转写 → 考点复习 → 试卷批阅」保留，在课程下加入课时层。每次课堂记录独立形成学习成果。
- 使用低内容密度的示例课程与占位文本，重点验证产品结构、入口和操作关系。
- 全部微信、硬件、录音、转写、生成与问答为演示。未调用真实麦克风或设备，选择文件不会上传。

## 页面结构（17 个页面，另含弹窗状态）

| 页面 | 主要内容与去向 |
|---|---|
| 微信登录 | 协议勾选、模拟授权与取消；授权后回到刚才的创建或录音操作 |
| 首页 | 课程卡片、新建课程、记录入口、录音卡状态 |
| 课程详情 | 按课时归档、搜索、可复习筛选、记录新课时 |
| 课时详情 | 录音、笔记、考点、试卷四阶段与前置依赖 |
| 记录一堂课 | 选择课程、小程序录音、录音卡录音、已有音频导入 |
| 课堂录音 | 开始、暂停/继续、结束确认；硬件模式模拟实体按键 |
| 录音卡回传 | 传输进度、取消重试、回传成功、保存到课程课时 |
| 转写与生成 | 转写、结构化笔记、原文时间关联的处理状态 |
| AI 课堂笔记 | 概要、知识要点、思维导图、重点标记、原文链接 |
| 编辑笔记 | 文本增删改、备注、重点标记、原始转写对照、保存或取消 |
| 录音与原文 | 时间戳段落、来源高亮、模拟播放器定位 |
| 考点与复习 | 核心考点、复习顺序、回看笔记、开始测试 |
| 押题练习 | 单选、多选、简答；逐题操作、题号导航、提交确认 |
| 试卷批阅 | 客观题正确数量、逐题答案与解析、回到复习、重新练习、浏览器打印 |
| AI 学习助手 | 选择课程与课时/整课范围、示例问答、来源跳转 |
| 我的 | 账户、课程统计、次数展示、录音设备 |
| 我的录音卡 | 发现与绑定、电量、存储、连接状态、录音入口、待回传文件、解绑 |

## Must 功能逐项映射

| 功能清单 | 原型入口 | 演示范围 |
|---|---|---|
| 微信登录 | 我的 → 微信登录；创建/录音前登录 | 勾选、授权、取消、恢复原操作；无真实微信接口 |
| 录音卡一键录音 | 记录一堂课 → 录音卡；我的 → 设备 | 模拟实体按键开始/结束，小程序状态随之改变 |
| 录音文件回传 | 结束硬件录音；设备待回传文件 | 进度、取消、重试、归档后生成笔记；协议未定 |
| 小程序内录音 | 首页 → 记录一堂课 | 模拟计时、暂停、继续、结束归档 |
| 语音转写 | 保存课时 → 转写与生成 → 录音与原文 | 处理进度、结果文本；口音/术语/噪声质量需真实验证 |
| 设备绑定与管理 | 我的 → 我的录音卡 | 登录关联、发现/绑定、静态电量/容量/连接、解绑 |
| 结构化笔记自动生成 | 课时详情 → AI 笔记 | 生成状态、概要、知识要点、可编辑结果 |
| 笔记编辑校正 | 笔记 → 编辑；长按或更多操作 | 增删改、重点标记、补充备注、保存；按课时隔离 |
| 原始转写对照 | 编辑笔记 → 原始转写对照 | 与当前编辑块关联的转写，展开/收起 |
| 课程分类与笔记列表 | 首页 → 课程 → 课时 | 新建、归档、定位具体课时 |
| 跳转原文 | 笔记长按/更多 → 跳转原文；块内时间链接 | 高亮来源段落，模拟播放器定位到关联秒数 |

## 推荐评审路径

1. 首页打开示例课程 → 课时 → 笔记 → 编辑并保存 → 跳转原文 → 考点 → 作答 → 批阅。
2. 首页新建课程 → 模拟微信登录 → 创建课程 → 小程序录音 → 结束 → 保存课时 → 生成笔记。
3. 我的 → 绑定录音卡 → 硬件模式录音 → 结束 → 回传 → 归档并生成。
4. AI → 选择已有笔记的课程与课时 → 提问 → 点击来源。

## 验证与边界

- `check.html` 为浏览器检查页，验证 17 页渲染、页面溢出、登录返回、课程创建、计时/生成、课时笔记隔离、原文定位、客观题评分、硬件回传与 AI 来源。
- 检查页会重置当前原型的本地演示数据。应使用临时浏览器配置运行，不要在保留演示数据的浏览器里随意打开。
- 示例简答题只提供参考答案，不伪造 AI 得分。演示 AI 问答是固定内容，无真实内容理解能力。
- 电量、存储、待回传文件和额度使用示例状态，未实现真实设备文件系统或权益扣减。
- 转写界面展示约定的时间关联；真实摘要与逐字稿的语义对齐需后续实现。
- 处理页离开后演示计时暂停，重新打开处理页可继续；不代表实际后台任务行为。
- 这是 HTML 可点击原型，不是可发布的微信小程序工程。
